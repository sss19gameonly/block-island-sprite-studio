# Sprite Studio v0.4.1 検証報告

2026-10-30

## 変更
- index.html：大盤面と既存スライダーを維持し、その下にA/B切替、小プレビュー、候補名、コピー操作を追加。
- 各案に画像・倍率・位置を保持。占有形状・盤面配置・表示条件は共通。
- 画像変更時は調整値を引き継ぐ（チェック解除で初期化）。初期化は編集中の案のみ。
- JSON v0.4.1に候補名、選択案、共通layout、variants A/Bを保存。画像包含チェックに対応。旧0.3/0.4読込を保持。台帳形式・保存キー・処理は変更なし。
- PNGは1マス128px、位置は420px基準盤面の座標から換算。128pxは1〜4マスの素材検討に十分な寸法とファイル負荷の折衷。プレビューは任意倍率、出力は端末非依存。PNG配置情報JSONに基準寸法、基準点、占有枠、画像範囲を保存。
- 元画像の透明域を維持し、占有枠と画像全体の和集合に2px余白。画像の赤み等の加工なし。
